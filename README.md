## 📚 About This Repository

This repository contains all the code, notes, and practice problems that I solve while learning Java and Data Structures & Algorithms.

I'm following the **Java DSA Roadmap by Raghav Garg (GeeksforGeeks)** and solving every concept by writing the code myself instead of simply watching the videos.

Whether you're a beginner or revising Java and DSA, you can follow this repository step-by-step.
